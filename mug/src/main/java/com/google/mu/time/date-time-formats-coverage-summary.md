# Date-Time Parsing Support & Coverage Summary

This document provides a feature parity matrix of various date-time formats and
details how they are handled by **Hutool 5** (`DateUtil.parse()`) and **Mug**
(`DateTimeFormats.parse*()` / `formatOf()`).

| Input Example                                                   | Mug Support | Hutool 5 Support | Details & Failure Modes                                                                                                                                                                                                                                                                                   |
| :-------------------------------------------------------------- | :---------: | :--------------: | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`2023-10-20`**                                                | ✅           | ✅                | Standard ISO-8601 Date.                                                                                                                                                                                                                                                                                   |
| **`10:30:00`**                                                  | ✅           | ✅                | Standard ISO-8601 Time.                                                                                                                                                                                                                                                                                   |
| **`10:30:00.123456789`**                                        | ✅           | ✅                | High precision nanosecond support.                                                                                                                                                                                                                                                                        |
| **`1:10AM`** / **`2:05 PM`**                                    | ✅           | ❌                | **Hutool:** Fails to parse time-only strings with `AM/PM` meridiem annotations.<br>**Mug:** Successfully infers 12-hour format structure.                                                                                                                                                                 |
| **`09:00:30AM`**                                                | ✅           | ❌                | **Hutool:** Fails to parse 12-hour times.<br>**Mug:** Successfully parses.                                                                                                                                                                                                                                |
| **`Mon, 2022-07-25`**                                           | ✅           | ❌                | **Hutool:** Presence of the weekday abbreviation falsely routes parsing to RFC-2822 formatting logic, which then fails.<br>**Mug:** Correctly parses weekday prefixes (via `formatOf`).                                                                                                                   |
| **`周一, 2022-07-25`**                                            | ✅           | ❌                | **Hutool:** Chinese weekday prefix on standard dates is not recognized.<br>**Mug:** Successfully parses (via `formatOf`).                                                                                                                                                                                 |
| **`2020-08-10 15点19:01`**                                       | ❌           | ❌                | Mixed formatting (Chinese `"点"` hour + colon `":"` minutes).<br>**Hutool:** Fails due to unhandled `"点"`.<br>**Mug:** Fails because both `15` and `19` are parsed as hours, producing the invalid pattern `yyyy-MM-dd HH点HH:mm`. Standard uniform Chinese date-times (e.g. `15点19分`) are fully supported. |
| **`1994-08-03 19:32:42 UTC`**                                   | ✅           | ❌                | **Hutool:** Space-separated timezones route parser to RFC-2822 formats, causing standard patterns to fail.<br>**Mug:** Correctly extracts space-separated timezones.                                                                                                                                      |
| **`2020-01-01T12:00:00 Asia/Shanghai`**                         | ✅           | ❌                | **Hutool:** Space-separated regional timezone names are unrecognized.<br>**Mug:** Successfully parses.                                                                                                                                                                                                    |
| **`2020/01/01T00:00, America/Los_Angeles`**                     | ✅           | ❌                | **Hutool:** Comma-separated timezone names are unrecognized.<br>**Mug:** Successfully parses.                                                                                                                                                                                                             |
| **`10/30/2014`** / **`30/01/2014`**                             | ✅           | ❌                | **Hutool:** Fails because it strictly requires a 4-digit year as the first component after normalization.<br>**Mug:** Dynamically infers and resolves unambiguous layouts (e.g. month-first vs day-first) based on values (`30 > 12`).                                                                    |
| **`2020-01-01T00:00:01-07:00[America/New_York]`**               | ✅           | ⚠️ *Partial*     | **Hutool:** Successfully parses, but discards/fails to preserve the regional ZoneId (`America/New_York`), resolving only to a fixed offset (`GMT-07:00`).<br>**Mug:** Correctly parses and preserves regional timezone rules.                                                                             |
| **`2019-3-21 12:20:15`** / **`2018-4-10`**                      | ✅           | ✅                | **Mug:** Successfully parses standard dates with single-digit months/days (e.g. `yyyy-M-dd`, `yyyy-M-d`).                                                                                                                                                                                                 |
| **`2:12:12`** / **`12:2`**                                      | ❌           | ✅                | **Mug:** Time strings with single-digit hour/minute/second values are unsupported unless AM/PM is present.<br>**Hutool:** Successfully parses.                                                                                                                                                            |
| **`2017.02.01`** / **`2017.02.01 12:23`**                       | ✅           | ✅                | **Mug:** Successfully parses dot-separated dates (e.g. `yyyy.MM.dd`, `d.M.yyyy` etc.).                                                                                                                                                                                                                    |
| **`20170201122345`** / **`20170201`**                           | ❌           | ✅                | **Mug:** Pure numeric date-time strings are unsupported (though `20170201` alone works for `parseLocalDate` specifically, it is not inferable by `formatOf`).<br>**Hutool:** Successfully parses.                                                                                                         |
| **`Tue Jun 4 16:25:15 +0800 2019`** / **`Wed Sep 16 CST 2009`** | ❌           | ✅                | **Mug:** JDK's default `Date.toString()` layout (weekday + month + day + time + zone + year) is not matched by the signature engine.<br>**Hutool:** Fully supported.                                                                                                                                      |
| **`01/02/03`** / **`01/02/2003`**                               | ❌           | ❌                | **Mug:** Ambiguous month/day layouts are rejected by default to prevent silent parsing bugs.<br>**Hutool:** Fails due to expected 4-digit year prefix.                                                                                                                                                    |
| **`1`** / **`1:10`** (no AM/PM)                                 | ❌           | ❌                | Single digit hour values without meridiem markers are rejected by both libraries for safety.                                                                                                                                                                                                              |
| **`2023-01-01T00:00:00.`**                                      | ❌           | ❌                | Trailing dot without fractional seconds is rejected by both libraries.                                                                                                                                                                                                                                    |
